## 5. 最终联合审计后的补充（2026-11-23）

- **P1（guard）**：`boot_guard.sh` 的 `unsuspend_owned` 只在 `User 0` 行出现正向
  `suspended=false`（或 `pm list packages` 确认已卸载）时删除 `suspended_by_nemu`
  标记；空输出、超时、部分 dumpsys 一律保留标记并计入失败。
- **P1（超时）**：`ShellResult` 新增 `indeterminate`；Root/Shizuku 超时标记为不确定。
  `FreezeStrategyController` 不再把超时当普通失败；`TargetFreezeService` 对不确定
  结果保留 applied 标记、原始基线和 guard 标记，交给下次恢复/开机守卫核验。
- **启动窗口**：`BootFreezeWorker` 在残留恢复后、应用策略前复查窗口；超过
  `delay + 300s` 记录“已跳过：超过开机冻结窗口”，不在活跃使用时冻结。
- **关机脚本**：模块不再按聚合 exit 0 截断 `restore_frozen.sh`；由 App 在自身
  校验通过后清空，失败命令可重放。
- **检测**：RESTRICT 的 ownership 也算 policyApplied；HIDE 详情优先展示已隐藏，
  不再与“未知”冲突。
- **分类规则（重新审计后的最终口径）**：
  - Root 管理器只含 Root 管理器（FinaSU/KernelSU/Magisk/KSU Next/SukiSU/APatch/
    WildKSU 等），请求 root 的普通工具不是 Root。
  - LSP 插件通过 `xposedmodule` meta-data **或 APK 内**
    `META-INF/xposed/module.prop`、`META-INF/xposed/java_init.list`、
    `assets/xposed_init` 自动识别；Hail、Scene、FuseHide、凪、若晴均为插件。
  - `moe.shizuku.privileged.api` 与 Stellar 为 Shizuku 管理器；ShizuStore、
    InstallWithOptions、Shizuku 安装器为 Shizuku 应用。
  - 系统 = PackageManager 预装标记（FLAG_SYSTEM / FLAG_UPDATED_SYSTEM_APP），
    不再依赖包名前缀；用户安装的工具（MT 管理器、Rootless Store、多系统工具箱、
    Komi Store 等）归用户。
  - 模块版本 1.14 / versionCode 15，zip SHA-256
    `198574b31bb36b1b575790a044521175202b4a8b68f08f09fc99fe89fc506f7c`。
