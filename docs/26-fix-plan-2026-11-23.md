## F1 + F6：清单保留名与非原子写入

### 问题

`<backup>/manifest.tsv`，再写清单覆盖它。`writeManifest` 直接写最终文件，
中断后可能留下可解析的截断清单。

### 修改

`cota/CotaPaths.kt`：

```kotlin
const val MANIFEST_NAME = "manifest.tsv"
const val TEMP_MANIFEST_NAME = ".manifest.tmp"

fun isReservedRootName(relativePath: String): Boolean =
    relativePath == MANIFEST_NAME || relativePath == TEMP_MANIFEST_NAME
```

`cota/CotaCommandBuilder.kt`：

```kotlin

    "printf '%s' ${q(manifestBase64)} | base64 -d > " +
        q("$backupDir/${CotaPaths.TEMP_MANIFEST_NAME}") +
        " && mv -f " + q("$backupDir/${CotaPaths.TEMP_MANIFEST_NAME}") +
        " " + q("$backupDir/${CotaPaths.MANIFEST_NAME}")
```

`cota/CotaController.kt` 的 `backup()` 在 `names.isEmpty()` 后增加：

```kotlin
val reserved = selected.filter { CotaPaths.isReservedRootName(it) }
if (reserved.isNotEmpty()) {
```

### 测试

## F2 + F3：目标侧符号链接与 TOCTOU

### 新增路径辅助（`cota/CotaPaths.kt`）

```kotlin
fun sourceParentPaths(relativePath: String): List<String> {
    require(isSafeRelativePath(relativePath))
    val segments = relativePath.split('/')
    return (1 until segments.size).map { depth ->
        SOURCE_DIR + "/" + segments.take(depth).joinToString("/")
    }
}
```

### 守卫（`cota/CotaCommandBuilder.kt`）

```kotlin
internal fun sourceGuards(relativePath: String): String {
    val target = CotaPaths.sourcePath(relativePath)
    val checks = mutableListOf(
        "case \"$(realpath -m ${q(target)})\" in " +
            "${q(CotaPaths.SOURCE_DIR)}/*) ;; *) exit 1;; esac"
    )
    CotaPaths.sourceParentPaths(relativePath).forEach { parent ->
        checks += "[ ! -L ${q(parent)} ]"
    }
    checks += "[ ! -L ${q(target)} ]"
    return checks.joinToString(" && ")
}
```

- `realpath -m` 已在设备 `/system/bin/realpath` 实测；越界路径返回 `exit 1`，命令失败关闭。
- 父目录/叶子符号链接全部拒绝；`mkdir -p` 只在这些检查之后执行，并在创建后复查一次
  父目录 `[ ! -L ]`。
- `backup()` 的每个 `cp` 前也加 `sourceGuards`，防止列目录后源文件被替换为链接。

### delete 同命令复核（替代独立 `rm`）

```kotlin
fun deleteVerified(
    backupDir: String,
    files: List<CotaBackupFile>
): String {
    require(files.isNotEmpty())
    val checks = files.joinToString(" && ") { file ->
        val backup = CotaPaths.backupPath(backupDir, file.name)
        val target = CotaPaths.sourcePath(file.name)
        sourceGuards(file.name) +
            " && [ -f ${q(backup)} ] && [ ! -L ${q(backup)} ]" +
            " && cmp -s ${q(backup)} ${q(target)}"
    }
    val targets = files.joinToString(" ") {
        q(CotaPaths.sourcePath(it.name))
    }
    return "$checks && rm -f $targets"
}
```

- 先对全部选中文件做 `cmp`，全部一致才在同一 shell 内 `rm -f`；任何不一致不删除任何文件。
- Controller 仍保留原有 manifest/备份副本 hash/当前 hash 校验，作为第二道防线。

### restore 同命令复核

每个文件：

```sh
<sourceGuards> &&
[ -f '<backup>' ] && [ ! -L '<backup>' ] &&
[ "$(sha256sum '<backup>' | cut -d' ' -f1)" = '<manifest hash>' ] &&
mkdir -p '<target parent>' && [ ! -L '<target parent>' ] &&
cp -p '<backup>' '<target>' &&
chown '<uid:gid>' '<target>' &&
chmod '<mode>' '<target>'
```

- `realpath` 在 `mkdir` 前检查一次，`mkdir` 后复查父目录不是链接，再复制。
- 不使用 `rm -rf`；叶子是链接时拒绝（`[ ! -L target ]`）。
- `chmod` 只接受 `isSafeRestoreMode`（3 位或 `0xxx`）。

### 测试

- `CotaCommandBuilderTest` 增：`deleteVerified` 含 `cmp -s` 且 `rm -f` 在同一条命令；
  `restore` 含 `realpath -m`、`sha256sum`、`mkdir -p`、父目录 `-L` 检查。
- `CotaControllerTest` 的 FakeRootBackend：
  - 识别包含 `rm -f ` 的命令并删除路径；
  - 识别 restore 命令中的 `cp -p` 模拟创建文件；
  - 新增“父目录/叶子为符号链接时命令失败、文件不变”测试（fake 可返回非零）。
- 真机：正常温控组备份/恢复仍成功；不创建真实符号链接做破坏性测试。

## F9：检测页的号码识别 HIDE 回归（来自 R1-4，P2）

### 问题

`detection/DetectionReader.kt:206-222` 只识别 legacy mode 的 `DISABLE_USER`/`SUSPEND`，
`HIDE` 落到 `strategy_` 或默认值，检测页会把已隐藏的号码识别显示成 SUSPEND 并判“不一致”。
`policy/TargetPolicy.kt:106-110` 已经正确映射 HIDE。

### 修改

新增 `detection/DetectionStrategy.kt`（纯函数，便于测试）：

```kotlin
object DetectionStrategy {
    fun resolve(
        target: Target,
        legacyNumberMode: String?,
        storedRaw: String?
    ): FreezeStrategy {
        if (target.packageName == Targets.numberidentity.packageName) {
            val legacy = legacyNumberMode
                ?.let { runCatching { NumberIdentityMode.valueOf(it) }.getOrNull() }
                ?.toStrategy()
            if (legacy != null && FreezeStrategyPolicy.isAllowed(target, legacy)) {
                return legacy
            }
        }
        val stored = storedRaw
            ?.let { runCatching { FreezeStrategy.valueOf(it) }.getOrNull() }
            ?: target.defaultStrategy
        return if (FreezeStrategyPolicy.isAllowed(target, stored)) {
            stored
        } else {
            target.defaultStrategy
        }
    }
}
```

`DetectionReader.catalogStrategy()` 改为：

```kotlin
return DetectionStrategy.resolve(
    target,
    readString("antifraud_numberidentity_mode"),
    readString("strategy_${target.packageName}")
)
```

### 测试

新增 `DetectionStrategyTest`：
- legacy `HIDE` -> `FreezeStrategy.HIDE`（号码识别）；
- legacy `DISABLE_USER` -> `DISABLE_USER`；
- legacy `OFF` + stored `HIDE` -> `HIDE`；
- 非号码识别目标的 stored 策略照常；
- 非法 stored 回落到目标默认值（且受 `FreezeStrategyPolicy` 限制）。
