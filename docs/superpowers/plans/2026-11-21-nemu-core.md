# Nemu Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Nemu Android app core: suspend/unsuspend `com.hihonor.ouc` and selected AI leaf packages via Root or Shizuku, with delayed post-boot application, dry-run, deny-list protection, and one-tap restore.

**Architecture:** A single-module Kotlin/Compose app. Pure core logic (command strings, deny list, targets) is unit-tested on the JVM. Two `PrivilegeBackend` implementations execute the same shell commands: `RootBackend` via `su`, `ShizukuBackend` via Shizuku's `IShizukuService.newProcess`. `FreezeController` applies `suspend → force-stop → clear-cache`; `BootReceiver` + WorkManager applies the policy after boot. No Hail dependency or Hail API/Intent is used.

**Tech Stack:** Kotlin 2.4.20, AGP 9.1.0, Gradle 9.7.1 wrapper, Compose BOM 2025.12.01, Material3, WorkManager 2.11.0, Shizuku API/provider 13.1.5, JUnit 4.13.2.

**Spec:** `../../03-design.md` (Nemu design). Package inventory: `../../02-package-inventory.md`. Device test plan: `../../04-test-plan.md`.

## Scope Decomposition

The full v1 scope has three relatively independent subsystems:

1. **Core (this plan):** update (`com.hihonor.ouc`), AI leaf packages, Root/Shizuku, boot delay, deny list, restore.
2. **Cloud/telemetry + anti-fraud (next plan):** carrier DM trio `disable-user`, hiview, `numberidentity`, AppOps/standby limits for `securityserver`/`awareness`.
3. **COTA/thermal (next plan):** root-only backup/clean/restore of `/data/cota/para`, risk confirmations.

This plan must produce working, testable software on its own before the advanced plans start. Do not mix carrier-DM `disable-user` or COTA file deletion into this plan.

## Global Constraints

- **No call site for `pm uninstall`, `pm uninstall --user`, or `pm disable-user` in this plan.** Only `suspend`/`unsuspend`, `force-stop`, and `pm clear --cache-only` are executed. `CommandBuilder.disableUser` may exist for the Phase 2 plan but must not be called by the controller or UI.
- **No Hail dependency.** Do not import `com.aistra.hail.*`, do not send Hail intents, do not read Hail data.
- **Hard deny list** in `DenyList` must be enforced in `FreezeController`, not only in UI.
- **Dry run defaults to true.** No actual write happens until the user turns it off.
- Package name: `com.nemu.hibernate`. `minSdk 30`, `targetSdk 36`, compile SDK 37.
- UI strings are Chinese; code identifiers English.
- One device-test target at a time; never batch-test red packages.
- All device writes are performed by the user from the app or from commands the user runs. The assistant only builds APKs and writes project files.

```kotlin
package com.nemu.hibernate.core

object CommandBuilder {
    fun suspend(pkg: String, userId: Int = 0): String =
        "pm suspend --user $userId ${quote(pkg)}"

    fun unsuspend(pkg: String, userId: Int = 0): String =
        "pm unsuspend --user $userId ${quote(pkg)}"

    fun forceStop(pkg: String): String =
        "am force-stop ${quote(pkg)}"

    fun clearCache(pkg: String, userId: Int = 0): String =
        "pm clear --user $userId --cache-only ${quote(pkg)}"

    fun disableUser(pkg: String, userId: Int = 0): String =
        "pm disable-user --user $userId ${quote(pkg)}"

    fun enable(pkg: String, userId: Int = 0): String =
        "pm enable --user $userId ${quote(pkg)}"

    fun appOpsBackground(pkg: String, restricted: Boolean, userId: Int = 0): String =
        "appops set --user $userId ${quote(pkg)} RUN_ANY_IN_BACKGROUND " +
            (if (restricted) "ignore" else "allow")

    fun standbyBucket(pkg: String, restricted: Boolean, userId: Int = 0): String =
        "am set-standby-bucket --user $userId ${quote(pkg)} " +
            (if (restricted) "restricted" else "active")

    private fun quote(value: String): String =
        "'" + value.replace("'", "'\\''") + "'"
}
```

```kotlin
package com.nemu.hibernate.data

import android.content.Context

class Settings(context: Context) {
    private val prefs = context.getSharedPreferences("nemu", Context.MODE_PRIVATE)

    var backend: String?
        get() = prefs.getString("backend", null)
        set(value) = prefs.edit().putString("backend", value).apply()

    var autoApplyOnBoot: Boolean
        get() = prefs.getBoolean("auto_apply", true)
        set(value) = prefs.edit().putBoolean("auto_apply", value).apply()

    var bootDelaySeconds: Int
        get() = prefs.getInt("boot_delay", 90)
        set(value) = prefs.edit().putInt("boot_delay", value.coerceIn(0, 600)).apply()

    var unsuspendOnShutdown: Boolean
        get() = prefs.getBoolean("unsuspend_on_shutdown", false)
        set(value) = prefs.edit().putBoolean("unsuspend_on_shutdown", value).apply()

    var dryRun: Boolean
        get() = prefs.getBoolean("dry_run", true)
        set(value) = prefs.edit().putBoolean("dry_run", value).apply()

    var lastBootResult: String?
        get() = prefs.getString("last_boot_result", null)
        set(value) = prefs.edit().putString("last_boot_result", value).apply()

    fun isEnabled(packageName: String): Boolean =
        prefs.getBoolean("target_$packageName", false)

    fun setEnabled(packageName: String, enabled: Boolean) =
        prefs.edit().putBoolean("target_$packageName", enabled).apply()
```

```kotlin
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update

data class LogEntry(
    val timestamp: Long,
    val level: String,
    val message: String
)

object ActionLog {
    private val _entries = MutableStateFlow<List<LogEntry>>(emptyList())
    val entries: StateFlow<List<LogEntry>> = _entries.asStateFlow()

    fun add(level: String, message: String) {
        val entry = LogEntry(System.currentTimeMillis(), level, message)
        _entries.update { (it + entry).takeLast(200) }
    }

    fun info(message: String) = add("INFO", message)
    fun warn(message: String) = add("WARN", message)
    fun error(message: String) = add("ERROR", message)
```

```kotlin
package com.nemu.hibernate.privilege

import com.nemu.hibernate.core.ShellResult
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext

class RootBackend : PrivilegeBackend {
    override val name: String = "Root"

    override suspend fun isAvailable(): Boolean = withContext(Dispatchers.IO) {
        runCatching {
            val result = execRaw("id")
            result.exitCode == 0 && result.output.contains("uid=0")
        }.getOrDefault(false)
    }

    override suspend fun exec(command: String): ShellResult = withContext(Dispatchers.IO) {
        execRaw(command)
    }

    private fun execRaw(command: String): ShellResult = runCatching {
        val process = ProcessBuilder("su").redirectErrorStream(true).start()
        process.outputStream.bufferedWriter().use { writer ->
            writer.write(command)
            writer.newLine()
        }
        val output = process.inputStream.bufferedReader().use { it.readText() }
        val exit = process.waitFor()
        ShellResult(exit, output)
    }.getOrElse { throwable ->
        ShellResult(-1, throwable.stackTraceToString())
    }
}
```

```kotlin
package com.nemu.hibernate.privilege

import android.content.pm.PackageManager
import android.os.ParcelFileDescriptor
import com.nemu.hibernate.core.ShellResult
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import moe.shizuku.server.IShizukuService
import rikka.shizuku.Shizuku
import java.util.concurrent.CountDownLatch
import java.util.concurrent.TimeUnit
import java.util.concurrent.atomic.AtomicInteger
import java.util.concurrent.atomic.AtomicReference

class ShizukuBackend : PrivilegeBackend {
    override val name: String = "Shizuku"

    override suspend fun isAvailable(): Boolean = withContext(Dispatchers.IO) {
        runCatching {
            Shizuku.pingBinder() &&
                Shizuku.checkSelfPermission() == PackageManager.PERMISSION_GRANTED
        }.getOrDefault(false)
    }

    override suspend fun exec(command: String): ShellResult = withContext(Dispatchers.IO) {
        runCatching {
            val service = IShizukuService.Stub.asInterface(Shizuku.getBinder())
            val process = service.newProcess(arrayOf("sh"), null, null)
            ParcelFileDescriptor.AutoCloseOutputStream(process.outputStream).use { stream ->
                stream.write(command.toByteArray())
            }

            val outputRef = AtomicReference("")
            val reader = Thread {
                runCatching {
                    val text = ParcelFileDescriptor.AutoCloseInputStream(process.inputStream)
                        .bufferedReader()
                        .use { it.readText() }
                    outputRef.set(text)
                }
            }.apply {
                isDaemon = true
                start()
            }

            val exitRef = AtomicInteger(-1)
            val done = CountDownLatch(1)
            Thread {
                runCatching { exitRef.set(process.waitFor()) }
                done.countDown()
            }.apply {
                isDaemon = true
                start()
            }

            if (!done.await(15, TimeUnit.SECONDS)) {
                runCatching { process.destroy() }
                reader.join(1000)
                ShellResult(-1, "timeout after 15s")
            } else {
                reader.join(1000)
                ShellResult(exitRef.get(), outputRef.get())
            }
        }.getOrElse { throwable ->
            ShellResult(-1, throwable.stackTraceToString())
        }
    }
}
```

```kotlin
package com.nemu.hibernate.policy

import com.nemu.hibernate.core.CommandBuilder
import com.nemu.hibernate.core.DenyList
import com.nemu.hibernate.core.Target
import com.nemu.hibernate.data.ActionLog
import com.nemu.hibernate.data.Settings
import com.nemu.hibernate.privilege.PrivilegeBackend

class FreezeController(
    private val backend: PrivilegeBackend,
    private val settings: Settings
) {
    suspend fun apply(targets: List<Target>): Boolean {
        var allOk = true
        for (target in targets) {
            if (!settings.isEnabled(target.packageName)) continue
            if (DenyList.isProtected(target.packageName)) {
                ActionLog.warn("拒绝冻结受保护包：${target.packageName}")
                allOk = false
                continue
            }
            val commands = buildList {
                if (target.suspend) add(CommandBuilder.suspend(target.packageName))
                if (target.forceStop) add(CommandBuilder.forceStop(target.packageName))
                if (target.clearCache) add(CommandBuilder.clearCache(target.packageName))
            }
            if (!executeAll(commands)) allOk = false
        }
        return allOk
    }

    suspend fun restore(targets: List<Target>): Boolean {
        var allOk = true
        for (target in targets) {
            if (!executeAll(listOf(CommandBuilder.unsuspend(target.packageName)))) {
                allOk = false
            }
        }
        return allOk
    }

    private suspend fun executeAll(commands: List<String>): Boolean {
        var allOk = true
        for (command in commands) {
            if (settings.dryRun) {
                ActionLog.info("DRY-RUN: $command")
                continue
            }
            val result = backend.exec(command)
            if (result.ok) {
                ActionLog.info("OK(${backend.name}): $command")
            } else {
                ActionLog.error(
                    "FAIL(${backend.name}, ${result.exitCode}): $command\n" +
                        result.output.take(500)
                )
                allOk = false
            }
        }
        return allOk
    }
}
```

```kotlin
class MainActivity : ComponentActivity() {
    private lateinit var settings: Settings
    private lateinit var manager: BackendManager

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        settings = Settings(this)
        manager = BackendManager(settings)

        Shizuku.addRequestPermissionResultListener { _, grantResult ->
            if (grantResult == PackageManager.PERMISSION_GRANTED) {

            NemuTheme {
                val scope = rememberCoroutineScope()

                var busy by remember { mutableStateOf(false) }
                var dryRun by remember { mutableStateOf(settings.dryRun) }
                val lastBootResult = remember { settings.lastBootResult ?: "尚未执行" }

                val logs by ActionLog.entries.collectAsState()

                LaunchedEffect(Unit) {
                    Targets.all.forEach {
                        enabled[it.packageName] = settings.isEnabled(it.packageName)

                MainScreen(
                    backendStatus = backendStatus,
                    lastBootResult = lastBootResult,
                    targets = Targets.all,
                    enabled = enabled,
                    dryRun = dryRun,
                    logs = logs,
                    busy = busy,
                    onToggle = { packageName, value ->
                        settings.setEnabled(packageName, value)
                        enabled[packageName] = value

                    onDryRunChange = {
                        settings.dryRun = it
                        dryRun = it

                    onRequestShizuku = {
                        runCatching {

                            val backend = manager.get()

                            } else {
                                FreezeController(backend, settings).restore(Targets.all)
                                backendStatus = manager.status()
                            }
                            busy = false
                        }
                    }
                )
            }
        }
    }
```

```kotlin
package com.nemu.hibernate.policy

import android.content.Context
import androidx.work.CoroutineWorker
import androidx.work.WorkerParameters
import com.nemu.hibernate.core.Targets
import com.nemu.hibernate.data.ActionLog
import com.nemu.hibernate.data.Settings
import com.nemu.hibernate.privilege.BackendManager
import com.nemu.hibernate.privilege.PrivilegeBackend
import kotlinx.coroutines.delay

class BootWorker(
    context: Context,
    params: WorkerParameters
) : CoroutineWorker(context, params) {

    override suspend fun doWork(): Result {
        val settings = Settings(applicationContext)
        if (!settings.autoApplyOnBoot) return Result.success()

        val manager = BackendManager(settings)
        var backend: PrivilegeBackend? = null
        var attempts = 0
        while (backend == null && attempts < 6) {
            backend = manager.get()
            if (backend == null) {
                delay(15_000)
                attempts++
            }
        }
        if (backend == null) {
            ActionLog.warn("开机执行失败：无可用权限")
            settings.lastBootResult = "失败：无可用权限（${System.currentTimeMillis()}）"
            return if (runAttemptCount < 2) Result.retry() else Result.failure()
        }

        val ok = FreezeController(backend, settings).apply(Targets.all)
        val resultText = if (ok) "成功" else "有失败"
        ActionLog.info("开机执行完成：$resultText")
        settings.lastBootResult = "$resultText（${System.currentTimeMillis()}）"
        return if (ok || runAttemptCount >= 3) Result.success() else Result.retry()
    }
}
```

- [ ] **Step 2: Implement BootReceiver**

`app/src/main/java/com/nemu/hibernate/policy/BootReceiver.kt`:

```kotlin
package com.nemu.hibernate.policy

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import androidx.work.BackoffPolicy
import androidx.work.ExistingWorkPolicy
import androidx.work.OneTimeWorkRequestBuilder
import androidx.work.WorkManager
import com.nemu.hibernate.data.Settings
import java.util.concurrent.TimeUnit

class BootReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        if (intent.action != Intent.ACTION_BOOT_COMPLETED) return

        val settings = Settings(context)
        if (!settings.autoApplyOnBoot) return

        val request = OneTimeWorkRequestBuilder<BootWorker>()
            .setInitialDelay(settings.bootDelaySeconds.toLong(), TimeUnit.SECONDS)
            .setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 30, TimeUnit.SECONDS)
            .build()

        WorkManager.getInstance(context)
            .enqueueUniqueWork("nemu_boot_apply", ExistingWorkPolicy.REPLACE, request)
    }
}
```
