## 8. 结果文案

结果统一由 `core/ResultReason.kt` 生成；原始命令、`OK/FAIL`、策略枚举名、
`DRY-RUN`、`PackageManager` 和 shell 输出只进 `ActionLog`。

| 场景 | 示例 |
|---|---|
| 单目标失败 | `天气：无法读取原始状态，未执行` |
| 限制失败 | `天气：限制失败（限制未生效）` |
| 批量失败 | `有失败，尝试 3，成功 1，失败 2；号码识别：操作前已被暂停，不接管；天气：无法确认隐藏状态` |
| 预检 | `无可用权限` / `没有启用的目标` / `自动救砖模式，已拒绝执行` |
| 云控 | `成功` / `有失败或拒绝：…（预览，未执行）` |
